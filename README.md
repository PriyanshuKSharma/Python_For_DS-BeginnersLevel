## ⚡ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/PriyanshuKSharma/Python_For_DS-BeginnersLevel.git
cd Python_For_DS-BeginnersLevel
```

### 2. Set Up a Virtual Environment *(recommended)*

```bash
python -m venv venv
source venv/bin/activate        # Linux / macOS
# venv\Scripts\activate         # Windows
```

### 3. Install Dependencies

```bash
pip install numpy pandas jupyter matplotlib scikit-learn
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Run a Python File

```bash
python OOP_Mastery.py
python SortingAndSearching/MergeSort.py
```
