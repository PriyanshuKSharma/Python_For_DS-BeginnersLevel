### 📊 NumPy at a Glance

```python
import numpy as np

# Array creation
arr  = np.array([[1,2,3],[4,5,6]])          # From list
zer  = np.zeros((3, 4))                      # Zero matrix
ones = np.ones((2, 5))                       # Ones matrix
rng  = np.arange(0, 99, 2)                  # Range with step
lsp  = np.linspace(0, 1, 100)               # 100 evenly spaced points

# Operations (vectorized — no loops needed!)
np.add(arr, arr)          # Element-wise add
np.sin(arr)               # Trigonometric
np.power(arr, 2)          # Squaring
np.mean(arr, axis=0)      # Column-wise mean
arr.reshape(3, 2)         # Reshape
```

### 🐼 Pandas at a Glance

```python
import pandas as pd

df = pd.read_csv('data.csv')    # Load data
df.head()                        # Peek at top 5 rows
df.describe()                    # Statistical summary
df.isnull().sum()                # Missing value counts

# Filter, group, aggregate
df[df['marks'] > 80]             # Boolean filtering
df.groupby('city')['marks'].mean()
df.sort_values('marks', ascending=False)
df.drop_duplicates(subset=['name'])
```

## ⚡ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/PriyanshuKSharma/Python_For_DS-BeginnersLevel.git
cd Python_For_DS-BeginnersLevel
```

### 2. Set Up a Virtual Environment *(recommended)*

```bash
python -m venv venv
source venv/bin/activate        # Linux / macOS
# venv\Scripts\activate         # Windows
```

### 3. Install Dependencies

```bash
pip install numpy pandas jupyter matplotlib scikit-learn openpyxl xlrd
```

### 4. Launch Jupyter

```bash
jupyter notebook                # Opens browser at localhost:8888
```

### 5. Run a Python File

```bash
# OOP showcase
python OOP_Mastery.py

# Sorting algorithms
python SortingAndSearching/MergeSort.py
python SortingAndSearching/QuickSort.py

# Practice scripts
python Revision/abstraction_prac.py
python Revision/linked_list_implementation.py
```
